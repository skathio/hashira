hashira

Reusable GitHub Actions workflows and composite actions for npm, NuGet and static-site releases.

Use it

jobs:
  ci:
    uses: skathio/hashira/.github/workflows/npm-package-ci.yml@<40-char-sha>
    permissions:
      contents: read
      pull-requests: write
      security-events: write
    with:
      library_ref: '<40-char-sha>'   # the same SHA as the uses: ref

What it carries for you

  • Three flowsnpm package, NuGet package, and a static site on GitHub Pages.
  • Pinned actionsEvery third-party action is pinned to a full commit SHA.
  • Deny-all permissionsEach job is granted only what it needs.
  • OIDC publishingTrusted publishing to npm and nuget.org, with no long-lived tokens.
  • Explicit releasesA dispatch with a bump picks the version. Nothing is inferred from commit messages.
  • Scan suiteosv, gitleaks, dependency review, CodeQL and actionlint.
